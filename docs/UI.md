# Nexus 个人博客 · 设计规范文档 (v2.0)

> **设计关键词**：深邃霓虹、玻璃拟态、流动视差、微交互叙事
> **核心意图**：在黑暗与光影的交界处，构建一座具有"数字花园"气质的个人知识空间。

---

## 1. 设计理念

以**深度感**和**流动性**为核心，模拟苹果官网的叙事滚动与空间层次。页面不仅是信息的容器，更是一个沉浸式的浏览环境。通过多层视差、动态粒子和自定义光标，让每一次滚动和悬停都成为细腻的交互反馈。

---

## 2. 色彩系统

采用**深色基底**配合**霓虹渐变**，营造科技感与活力。

| 角色 | 色值 | 说明 |
|------|------|------|
| 背景主色 | `#0a0a0f` | 深邃黑，提供稳固的视觉根基 |
| 表面色 | `#12121a` | 卡片、容器背景 |
| 次级表面 | `#1a1a28` | 输入框、悬浮面板 |
| 主文字 | `#e8e8f0` | 高可读性暖白 |
| 次要文字 | `#9d9db5` | 辅助信息，降低视觉重量 |
| 强调紫 | `#a78bfa` | 主色调，用于渐变起点 |
| 强调粉 | `#f472b6` | 点缀色，光标悬停、互动反馈 |
| 强调蓝 | `#60a5fa` | 技术类标签、渐变支点 |
| 强调绿 | `#34d399` | 生活类标签、成功状态 |

**渐变规范**：
- **主渐变**：`linear-gradient(135deg, #a78bfa, #f472b6, #fb923c)` — 用于 logo、主要按钮、标题高亮。
- **次级渐变**：`linear-gradient(135deg, #60a5fa, #a78bfa, #f472b6)` — 用于统计数字、视差按钮。
- **装饰渐变**：`linear-gradient(135deg, #34d399, #60a5fa, #a78bfa)` — 用于特色卡片图像区。

## 3. 字体排印

| 用途 | 字体栈 | 字重 | 备注 |
|------|--------|------|------|
| 正文、UI | `'Inter', 'PingFang SC', 'Microsoft YaHei', system-ui` | 400–500 | 优先系统字体，保证渲染速度 |
| 等宽/数字 | `'SF Mono', 'Fira Code', 'Consolas', monospace` | 800–900 | 用于统计数字、Logo、代码片段 |
| 标题（Hero） | 继承上述 | 900 | 配合 `letter-spacing: -1.5px` 增强张力 |

**排版细节**：
- 全局行高 `1.7`，确保文字呼吸感。
- 圆角体系：`12px`（小）、`18px`（常规）、`24px`（卡片）、`32px`（大容器）、`50px`（药丸形）。

## 4. 玻璃拟态与质感

核心视觉风格：**Glassmorphism 2.0**。

| 属性 | 值 | 说明 |
|------|----|------|
| 背景 | `rgba(18, 18, 26, 0.6)` | 半透明深色基底 |
| 模糊 | `blur(30px) saturate(180%)` | 强模糊与色彩增强 |
| 边框 | `1px solid rgba(255,255,255,0.06)` | 微妙的高光边缘 |
| 阴影 | `0 8px 40px rgba(0,0,0,0.4)` | 浮起感 |

应用范围：导航栏、卡片悬停态（伪元素）、视差展示区背景。

## 5. 动效与交互规范

### 5.1 光标系统
- **自定义光标**：固定跟随鼠标，由外圈（28px 描边圆）和内点（6px 实心圆）组成。
- **延迟跟随**：外圈采用 `0.12` 缓动系数，内点 `0.35`，形成拖尾感。
- **悬停态**：当接触可交互元素（链接、按钮、卡片等）时，外圈放大至 55px，变为粉色，并出现半透明填充；内点同步放大至 10px 并变为粉色。移动端自动隐藏。

### 5.2 滚动视差（Parallax）
- **视差区域**：`85vh` 高度，包含背景层与内容层。
- **速度差异**：背景层按元素在视口中的垂直位置反向移动，移动幅度为自身高度的 20%，形成"背景缓慢流淌"的效果。
- **触发动画**：当视差区域进入视口 30% 时，标题、描述和按钮依次向上淡入（`opacity + translateY`），营造叙事感。
- **实现方式**：使用 `requestAnimationFrame` 优化滚动性能，`will-change: transform` 提升合成层渲染。

### 5.3 微交互
- **打字机效果**：Hero 标题循环播放 4 组短语，带光标闪烁。
- **数字递增**：统计数据在进入视口时从 0 滚动至目标值，缓动函数 `ease-out`（三次方缓出）。
- **卡片 3D 倾斜**：普通卡片随鼠标位置产生最大 8° 的 X/Y 轴旋转，离开时回弹。
- **按钮涟漪**：点击订阅按钮时，从点击处扩散半透明圆形波纹。
- **主题切换**：点击导航星星图标，背景色温发生渐变，图标旋转 180° 切换符号。

### 5.4 过渡动画
- 全局使用 `cubic-bezier(0.22, 1, 0.36, 1)` 缓动函数，平滑而富有弹性。
- 弹性动画使用 `cubic-bezier(0.34, 1.56, 0.64, 1)`，用于按钮悬停放大、回到顶部弹跳等。

## 6. 组件规范

### 6.1 导航栏 (Navbar)
- **位置**：固定顶部居中，圆角药丸形。
- **状态**：默认半透明毛玻璃，滚动超过 60px 后加深背景并缩小内边距。
- **活跃态**：对应滚动位置的链接显示紫色半透明背景。
- **响应式**：移动端隐藏常规链接，通过汉堡菜单展开竖直列表。

### 6.2 筛选标签 (Filter Tags)
- 默认透明背景、细描边。
- 悬停时边框变为紫色，文字变白，上移 2px。
- 激活态使用主渐变背景，无边框，带阴影。

### 6.3 文章卡片 (Post Card)
- **基础卡片**：毛玻璃表面，圆角 24px，内边距 28px。悬停时上浮 6px，边框渐隐，出现紫色描边光晕，标题渐变着色。
- **特色卡片**：横跨全宽，左侧为渐变色块 + 图标，右侧为内容。
- **卡片入场**：使用 Intersection Observer 实现滚动渐显，配合 `translateY(30px)` 上浮动画，每个卡片带有交错延迟。

### 6.4 按钮 (Button)
- **主要按钮**（导航 CTA、订阅）：使用主渐变背景，白色文字，悬停放大 1.05 倍并增强投影。
- **视差按钮**：次级渐变背景，悬停时轻微放大。
- **交互反馈**：点击时通过绝对定位的 `span` 元素生成水波纹。

### 6.5 订阅区 (Newsletter)
- 深色卡片背景，中央放射状光晕。
- 输入框为深色表面，聚焦时边框变紫并出现外发光。
- 提交按钮具有涟漪反馈，并模拟订阅成功状态（文字变为"✓ 已订阅！"，背景变绿 2.2 秒后恢复）。

---

## 7. 布局与网格

- **主容器**：最大宽度 `1100px`，水平居中，内边距 `140px 28px 60px`（移动端减小）。
- **文章网格**：`grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))`，自动适配列数，间距 26px。
- **视差区**：高度 `85vh`，最小 550px，最大 800px，保持视觉冲击力。

---

## 8. 无障碍与性能

- **滚动条**：自定义细窄样式，颜色 `#2a2a3a`。
- **Reduced Motion**：虽然未显式实现 `prefers-reduced-motion`，但所有动画均可通过 CSS 禁用覆盖。建议生产环境添加媒体查询。
- **性能**：粒子数量控制在 45 个以内，使用 `will-change` 仅应用于视差背景层，光标动画使用 `requestAnimationFrame`。
