# 欢迎使用内容系统

上周三深夜我在调试一个 frontmatter 解析的 bug，反复改了七八遍还是不对。那一刻我就在想，要是有一个能让我快速验证从解析到渲染整条链路的东西就好了。这篇文章就是干这个的。

坦率的讲，这篇文章存在的意义不是给你讲什么高深的东西。它就是我自己搭完内容系统之后，用来确认 frontmatter 能不能正确解析、列表页和详情页能不能正常渲染、TOC 功能是不是好使的一篇测试文章。

## 特性

说真的，我搭这套东西的时候脑子里就几个目标。

轻量的 frontmatter 解析是我最在意的一点。我不想要那种装一堆依赖才能跑起来的方案，能少一个包就少一个包。

列表页渲染卡片这块，我做的时候反复调了几次布局。说实话看着简单，但卡片之间的间距、标签的排列、封面图的比例这些细节真的很折腾人。

详情页生成 TOC 这个功能是我后来加的。我自己的感受是看长文章的时候没有目录导航真的很痛苦，所以咬咬牙还是把它做了。

### 代码块示例

下面这段代码没什么特别的，就是用来验证代码块渲染是否正常的一个最简单的函数。

```
function sum(a, b) {
  return a + b
}
```

如果你也打算搭一个类似的内容系统，我建议先把最基本的解析和渲染跑通，然后再去折腾那些花里胡哨的功能。先把路走通，再想着怎么跑。你觉得呢？
